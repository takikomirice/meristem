# Meristem v0.2.0

Windows x64向けの実験版です。VS Codeのコーディネーターが独立したCodex CLIワーカーに工程を割り当て、相談、報告、Git統合を管理します。

## v0.1.0からの変更

- 利用者の承認を受けてワーカーを増員し、複数の候補を統合後の同じコミットで検証できます。相談で保留した工程は、承認済みの変更を適用して再開できます。
- 工程ごとにモデル・推論強度・権限を指定できます。読み取り専用ワーカーは確認したコミットと検証結果を報告し、コーディネーターがその報告を採用すると後続工程が着手可能になります。
- ワーカーのターミナルに状態、活動、相談、直近の成否を表示します。同じチャット内で確認できた設定変更は `[設定変更]` の1行で表示します。標準Codexの履歴も確認できます。
- 専用環境の導入前診断、版2の工程表からの設定生成、導入と復元の手順を整備しました。

## ダウンロードと導入

| ファイル | 内容 |
| --- | --- |
| `meristem-v0.2.0-windows-x64.zip` | 本体、補助拡張、Node.js、固定済みの依存ライブラリ、ライセンス、日英の導入ガイド |
| `meristem-chat-control-0.2.0.vsix` | 補助拡張の単体パッケージ |
| `SHA256SUMS.txt` | ZIPとVSIXのSHA-256 |

初めて導入する場合はWindows x64用ZIPを展開して、同梱のREADMEに従ってください。Windows、Git、VS Codeと公式Codex拡張、.NET Framework、PowerShell、専用プロファイルでの正式ログインとRunPermitの承認が必要です。実機で確認したCodex CLIは `0.169.0-alpha.11.1` です。[日本語の導入ガイド](https://github.com/takikomirice/meristem/blob/v0.2.0/docs/releases/INSTALL.ja.md)

専用環境で読み取り専用への引き継ぎ、旧Git書き込み許可の非継承、報告採用後の後続工程解放まで確認しました。Workerの自動レビュー自身による拒否は未観測です。この配布物を使った別PCでの実モデル試験は未実施です。[総合受入記録](https://github.com/takikomirice/meristem/blob/v0.2.0/docs/validation/chat-control/worker-coordination-acceptance.md)

## English

Experimental Windows x64 release. This update adds approved Worker expansion, integration checks at the final commit, consultation and plan amendments, per-task model, reasoning and permission settings, and report-based acceptance of read-only work. Worker terminals show activity, consultations and confirmed settings changes within a chat.

Download the Windows x64 ZIP for the runtime, bundled Node.js, helper extension and setup guides. Use the standalone VSIX when you already have the runtime. Check both downloads against `SHA256SUMS.txt`. The dedicated-environment trial used Codex CLI `0.169.0-alpha.11.1`. Git, VS Code with the official Codex extension, official authentication, and RunPermit approval are required. [English setup guide](https://github.com/takikomirice/meristem/blob/v0.2.0/docs/releases/INSTALL.en.md)
