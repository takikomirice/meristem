## 実行中に見つかった修正

- 起動時に照合した設定を保存し、MCPの状態応答で実適用値を確認できるようにした。旧レコードの未記録値は補完しない。
- 未解決要求をruntimeが全体4件で切り捨てる問題を修正した。表示側のページングと通信サイズ上限を維持し、5人目の実ランタイムfixtureからの質問を取得・回答できた。
- 同一attemptの枠予約と起動確定が、同じ登録通知を2回書いていた。予約を開始前状態で保存し、登録通知は起動確定時に1回記録する。相談の履歴は作成・回答・取消などの遷移ごとに表示する。既存イベントと親の再開判定も読み取れる。
- 状態が変わるたびに端末が担当・権限・タスクを全行再掲していた。初回に全体を表示し、以降は最後に実際に描画した状態からの変更分だけを表示する。
- 登録前に済んだ増員・工程表改訂が新しい担当タブへ再掲される問題を修正した。試行中の正式履歴ではAの2件とBの3件は別々のコマンドだった。表示修正版で5件を再生して検索・読み取り・Git操作を区別し、数値だけの終了表示を成否の説明に変えた。同じ取得内の連続した同種の活動は件数を表示する。時間経過による注意表示を外し、最後の活動通知時刻と接続状態を表示する。
- 追加の表示修正で、通常の初回を3行にし、権限の元の表示は担当詳細から確認できるようにした。ファイルの進行・成功・失敗を「ファイル読み取り中／完了／失敗」とし、成否不明は「終了」、汎用コマンドは「コマンド実行終了」と成否を表示する。自動で開く担当タブは入力フォーカスを維持するようにし、拡張の回帰試験で確認した。
