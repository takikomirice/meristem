## 実装

- `src/actors.ts`: nativeが取得した接続元PID／作成identity、所有jobと実MCP metadataのthread／turnを照合し、登録から役割を導出する。引数のcallerやroleは受け付けない。
- `src/mcp.ts`: 公式SDKのstdio窓口、厳密なschema、fixture scopeと一回限りのRunPermit、作成・指示・報告・停止／再開。質問配送とGit受入は未公開。`record_decision`は新担当／正常完了履歴の継続だけ。
- `src/store.ts`／migration 002: binding履歴、報告、fixtureの配送予算を永続化。新ownerでの再bindingには新しい人の確認を要求し、配送不明・終了未確認を再開しない。
- `src/workers.ts`とnative: 実catalog／MCP接続、rootとprovider、前attempt終了、cleanなGitを確認。履歴は永続化して新owner／epoch／attemptでresumeする。isolation検査は排他的に作った一時ファイルだけを片付け、既存ファイルを保持する。
- 補助拡張: actor・attempt・要求設定・現在状態と限定ログを表示。後から作られたattemptを表示し、古い未終了attemptを履歴で隠さない。入力を転送せず、重複close／明示停止／programmatic disposeを区別する。
