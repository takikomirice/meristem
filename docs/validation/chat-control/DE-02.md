# DE-02: 設定生成と不変なビルドsnapshot

2026-11-17（日本時間）。[開発環境計画のDE-02](../../superpowers/plans/2026-11-17-development-test-environment-first.md#de-02-設定生成と不変なビルドsnapshot)のみを実装。着手時HEADは `fcdc957`、ブランチは `docs/worker-coordination-plan`、未コミット変更なし。

## 実装と範囲

`src/development.ts` に `prepareEnvironment`、`recordBuildCompletion`、`snapshotBuild`、`prepareRun` を追加した。環境manifest、snapshot manifest、run sessionを分け、installerの固定レイアウトと既存receiptを再利用する。installer本体は `InstallSpec` の型exportだけを追加し、動作・公開設定形式・復元処理は変更していない。

選定済みNode・Codex・Codeのパスとhash、公式拡張のmetadataを固定する。古いreport・更新された実体を自動許可しない。実行用JS、native3実体、拡張、migration、lockfileの実行依存とTypeScriptだけをsnapshotへcopyする。認証領域・公式exe・公式拡張本体はcopyしない。別build ID、runId、pipe、stateDirectoryを生成し、旧permit・owner/epoch/attempt・DB・送信数を読み込まない。送信枠は省略時0。

MC-02の実UI・自動レビュー・履歴再開に関する留保は[対応表](worker-coordination-compatibility.md)と[DE-01記録](DE-01.md)のまま。専用authHomeや残プロセスを推測して変更・停止していない。モデル、実VS Code、sandbox、UAC、外部Gitへの送信・接続は `not_run`。Gitを使う試験はローカルfixtureだけ。DE-03のlease／終了・復元、DE-04の開発CLI、DE-05の実機2回試験は未着手。

## 判断

- 現在のクリーンな作業ブランチで実施し、Windows PowerShellと `.local/de02/` のログを使用した。スキルのBash補助スクリプトや別worktreeを形式のために追加していない。
- `recordBuildCompletion` は、呼出元が成功・終了を確認したビルドの出力hashを記録する薄いAPI。コンパイラの成功やソース鮮度を推測しない。誤って成功前に呼ぶと古い出力を固定するため、後続runnerで必ずbuildをawaitする。明示した別buildRootにも対応し、既存 `build-native.ps1 -OutputDirectory` を利用できる。
- snapshot生成と設定生成は同期的にcopy・検証し、既存ファイルを書き換えない。入力変化や途中失敗の出力は自動削除しない。manifest/sessionが確定する前の部分出力は起動不可として残す。寿命管理はDE-03の責務。
- 独立レビューで、wake上限12との不整合と生成先planの同時編集検出漏れを確認。両方をRED→GREENで修正した。追加の自己レビューで公式拡張metadataの固定と隔離buildRootの扱いを確認した。
