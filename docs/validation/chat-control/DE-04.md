## 実装

- `src/development.ts`: `selectRefresh` と `refreshDevelopmentRun` を追加。DE-02の不変snapshot／新run生成と、DE-03の停止・復元・receipt／lease照合を再利用。scenarioの既存検査を共通化して停止前にも実施する。
- `test/live/development.ts`: `inspect | prepare | start | status | stop | refresh | restore` を追加。`npm run development -- <操作>` が入口。inspectは読取り、prepareは専用成果物の生成、live操作は明示した環境・sessionと `--live` を要求する。既存受入runnerの既定動作は変更しない。
- logicは明示した関連テストだけを実行。拡張・runtime・launchは新snapshotを要求し、所有runの停止・復元後に、新しいrunと専用hostで反映。未知の変更種別も再起動を選ぶ。停止unknownでは起動せず、CLIは終了コード1を返す。
- 副作用前の `refresh.json` と、後継run起動前の `refresh-result.json` を排他的に作成。二重CLI、途中中断、起動結果不明の再送を拒否し、後継sessionを照合可能にする。
- 日英READMEと[開発手順](../../development-environment.ja.md)を更新。新規依存、sandbox setup、認証操作、モデル送信、常駐処理、watchからの自動live再起動は追加しない。
